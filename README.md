# ecommerce
🎯 Objetivos

Diseñar y desarrollar un ecommerce enfocado en productos de plantas y jardinería. Implementar funcionalidades dinámicas con JavaScript para la gestión de productos y carrito. Crea una interfaz visual clara, atractiva y fácil de usar para el usuario. Construir un diseño responsivo que funcione en móvil, tableta y escritorio. Aplique la metodología Mobile First, desarrolle primero para dispositivos móviles y escalando a pantallas mayores.

🛠️ Tecnologías

HTML5

CSS

JavaScript

📋 Requisitos

Funcionalidades en JavaScript

Gestión del carrito mediante una función que recibe el ID del producto y lo almacena en un array. Cálculo del total del carrito sumando los precios de los productos. Filtrado de productos por categoría. Ordenación de productos de menor a mayor precio utilizando .sort(). Simulación de sesión de usuario (login básico o almacenamiento local).

 Maquetación y estilos

Uso de CSS Grid para la estructura del diseño. Implementación de variables CSS para mantener consistencia en colores, tamaños y estilos. Uso de Media Queries para adaptar el diseño a distintos dispositivos.
